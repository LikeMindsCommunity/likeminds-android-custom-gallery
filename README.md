# LikeMinds Custom Gallery for Android

A WhatsApp-style media picker for any Android app. No LikeMinds account required.

[![Maven Central](https://img.shields.io/maven-central/v/community.likeminds/likeminds-custom-gallery.svg)](https://central.sonatype.com/artifact/community.likeminds/likeminds-custom-gallery)
[![License](https://img.shields.io/badge/license-Apache%202.0-blue.svg)](LICENSE)

## What it does

Browse and multi-select images, video, documents and audio, then edit before sending:

- **Crop** images
- **Freehand draw** and **text overlay** on images
- **Trim** video
- **Audio waveform** playback

## Install

```groovy
implementation 'community.likeminds:likeminds-custom-gallery:1.3.0'
```

## Where it is used

This is the picker behind the LikeMinds
[Chat](https://github.com/LikeMindsCommunity/likeminds-chat-android-community-archv1) and
[Feed](https://github.com/LikeMindsCommunity/likeminds-feed-android) Android SDKs, extracted so it
can be used on its own.
